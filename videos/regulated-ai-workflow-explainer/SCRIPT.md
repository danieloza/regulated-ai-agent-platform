# Narration

1. Most AI agent demos ask one question: can the agent complete the task? In a regulated environment, that is not enough.
2. A request first enters source-bound RAG, where every answer must be grounded in approved evidence. The policy engine then decides: allowed, denied, or approval required.
3. If a tool is needed, the gateway grants only the exact scope. No shell. No direct database credentials. Sensitive writes stop for independent human approval.
4. Before a change reaches production, Policy Replay tests it against historical runs and adversarial evaluations. The Security Twin reconstructs attack paths and calculates the modeled blast radius.
5. Release Assurance combines those signals into an evidence-backed GO or NO-GO decision, protected by maker-checker separation and an integrity attestation.
6. The platform does not deploy automatically. It proves what may be authorized, why, and by whom.
7. Regulated AI Agent Platform. Evidence before authority.
